# Tahir Akram Portfolio Website

A one-page personal portfolio website for Tahir Akram, designed to present his journey from Pakistan to the United States, legal background, entrepreneurship, restaurant operations, real estate/construction work, community impact, and current projects.

## Files

- `index.html` — complete website with CSS and JavaScript included inside the file
- `assets/tahir-akram.jpg` — current hero/about photograph
- `CONTENT-NOTES.md` — checklist of information to collect next

## Run locally

Double-click `index.html`, or open the folder in VS Code and use Live Server.

## Publish with GitHub + Vercel

1. Create a new GitHub repository, for example `tahir-akram-portfolio`.
2. Upload `index.html`, `CONTENT-NOTES.md`, `README.md`, and the `assets` folder.
3. Go to Vercel and create a new project from that GitHub repository.
4. Framework preset: `Other`.
5. Build command: leave blank.
6. Output directory: leave blank.
7. Deploy.

Because this is a static site, no build process is required.
